# 彻底移除死板章节与字数限制优化方案

## 1. 根因分析
原有系统在 Stage 2 和 Stage 6 中设置了极其死板的“八股文”约束：
- 强制要求固定 4 个小标题（问题是什么、架构怎么解、工业界代价、落地法则）。
- 强制要求全文 1200-1800 字，甚至在校验器中硬性判定 `<900` 字不合格。
- **后果**：无论推文素材多么轻量或精炼，LLM 为了凑满这 4 个固定章节和 1500 字，只能车轱辘话来回倒、水字数、无病呻吟，导致文章冗长又空洞。

## 2. 改造方案
1. **彻底解除固定章节束缚**：
   - 废除 `headingProblem` / `headingArchitecture` / `headingIndustry` / `headingTakeaways` 四联装硬编码字段。
   - 章节数量和标题由 LLM 根据具体素材与技术事实自然组织（如 2 到 4 个章节均可，以讲清事实机制为准）。
2. **彻底废除 1200-1800 字限制**：
   - 从 Prompt 中删除“1200-1800 字”要求。
   - 从校验器中移除任何强制字数下限（如 <900 字报错）。
   - 以“实事求是、言简意赅、拒绝车轱辘话注水”为核心原则。
3. **占位符自然内嵌**：
   - 第一行为 `# 主标题`，随后放 `{{HEADER_IMAGE}}`。
   - 正文中自然容纳 `{{SVG_ARCH}}` 与 `{{SVG_SEQ}}` 矢量架构与时序图，不再硬性限制必须在“第 2 节”。
4. **保留核心质量防线**：
   - 保持空行分段，严禁文字砖。
   - 严禁素材外凭空捏造（无 fallback）。
