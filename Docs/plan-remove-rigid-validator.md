# 移除过度校验与死板规则方案

## 1. 根因反思
在之前的修改中，陷入了“用死板代码规则规训 LLM 写作”的严重误区：
- 正则死数自然段数量（强制每节 >=2 段，否则报错打回）。
- 正则强制小标题数量。
- 正则死抠百分比数字是否一字不差在素材中出现。
这种“正则做题家”逻辑极度不合理，导致 LLM 为了满足机械规则，输出极其生硬呆板、削足适履的文字砖。

## 2. 优化方案
1. **彻底废除机械死板校验**：
   - 彻底删除段落数硬性比对（不再数自然段数量）。
   - 彻底删除小标题数量强制要求。
   - 彻底删除百分比数字逐字正则死抠。
2. **极简宽容的底线保障**：
   - 仅保留最基础的安全底线：正文非空（>100字），能提取出一级标题。
   - 占位符 `{{HEADER_IMAGE}}`、`{{SVG_ARCH}}`、`{{SVG_SEQ}}` 若 LLM 遗漏，组装时自动在合适位置优雅补入，绝不因为缺少一个占位符就打回报错！
   - 提示词以真实、自然、接地气的人类工程师口吻为导向，不再设置条条框框的机械要求。
