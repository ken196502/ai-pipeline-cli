# 简化 Grok 网页端提示词方案

## 1. 根因分析
在 `execute.ts` 的 Stage 4 中，代码误将 Grok 网页聊天框当成了 API 的 `system` 字段，硬塞了一整段冗长的 API 式英文系统提示词（`You are an expert AI systems researcher... Requirements 1, 2, 3... DO NOT...`）。
- **荒谬性**：Grok 网页版自带内置系统人设和搜索引导，根本不需要外部用户在聊天框里注入一套伪造的 System Prompt。
- **负面影响**：上千字符的模板废话导致输入模拟时间极长、易被前端反作弊风控、浪费上下文，而且破坏了直接获取一手技术动态的自然搜索效果。

## 2. 优化方案
1. **彻底废除 API 式伪系统提示词**：
   - 彻底删除 `You are an expert... Requirements...` 这类死板模板。
2. **改为自然、精准的人类搜索提问**：
   - 直接把选定的推文核心议题作为核心检索目标，以简洁自然的工程师口吻提问：
     `联网搜索关于 "${primaryTopic}" 的最新权威技术分析与一线工程实践，总结核心事实、落地机制与技术权衡。`
   - 短小干脆，几秒钟即可完成输入，最大限度发挥 Grok 联网检索能力。
